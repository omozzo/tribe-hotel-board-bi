# Tribe Hotel Board BI Dashboard

## Run locally

1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run:

```bash
pip install -r requirements.txt
streamlit run app.py
```

The dashboard includes editable board inputs, interactive charts, service-charge analysis, outsourcing scenarios, manpower scenarios, a qualitative legal-risk matrix, an implementation roadmap, and CSV export.

The default values are illustrative where the source presentation does not provide numerical data. Replace them with Tribe Hotel's actual figures before presenting financial conclusions to the Board.
